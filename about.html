HoloRuminant project

About HoloR-tools

Open-access software from the HoloRuminant project for the analysis of ruminant microbiome data.

The project

HoloRuminant studies the microbiomes of the ruminant holobiont: the animal together with the microbial communities that live in and on it. The project is funded by the European Union's Horizon 2020 research and innovation programme. More information is on the HoloRuminant project website and the CORDIS project page for grant agreement 101000213.

The tools

The tools listed on this site were developed during the project. They support the analysis of ruminant microbiome data, including associating microbial features with host variables, identifying beneficial microbes and building microbiome networks. Some are command-line tools and workflows; others run entirely in the web browser, so no data leave the user's computer.

The list was first compiled for Deliverable D1.4, "HoloR-tools" (Work Package 1), prepared by the Norwegian University of Life Sciences (NMBU), Queen's University Belfast (QUB) and the Natural Resources Institute Finland (Luke). CowPI2 is described in Deliverable D1.5.

Adding or updating a tool

The site is built from two plain-text data files. Members of the HoloRuminant team can add a tool or update an entry by following the instructions in the site repository README.
